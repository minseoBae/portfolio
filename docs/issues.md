# Issues & Troubleshooting — Portfolio

> 옵시디언 볼트 연동용 이슈/트러블슈팅 문서. 발생한 문제와 해결 과정을 실시간으로 갱신한다. 전체 진행 상황은 [[progress]] 참고.

## 해결된 이슈

### 전화번호 노출 (개인정보)
- **현상:** 푸터 및 연락처 섹션에 전화번호가 그대로 노출됨.
- **해결:** 푸터(PR #5)·연락처 폼(PR #3) 양쪽에서 전화번호 노출 제거.
- → [[progress]]의 핵심 제약 "내부 보안 정보·연락처 노출 금지" 근거가 된 사례.

### Framer Motion SSR 콘텐츠 이슈
- **현상:** `MotionDiv`로 감싼 콘텐츠가 SSR 시점에 정상 렌더링되지 않는 문제.
- **해결:** 정적 SSR 콘텐츠로 렌더링하도록 수정 (PR #4).

### About 섹션 통계 수치 근거 부족
- **현상:** About 섹션의 통계/소개 문구가 추측성 수치를 포함.
- **해결:** 근거 기반 문구로 개편 (PR #6, `b33d853`, 2026-09-08).
- → [[progress]]의 핵심 제약 "성과/수치 추측 금지" 근거가 된 사례.
- **후속 (2026-09-09, PR #9):** 개편된 문구가 "면접관 설득용" 팩트 카드 톤이라 어색하다는 사용자 피드백 → 원래의 자연스러운 서술형 톤 + Stats 슬로건(직접/빠른/함께/도전)으로 복원하되, Spring Batch/Redis 근거 문장 1개만 본문에 남김. **현재 유효한 버전은 PR #9 쪽이며, 이 항목의 "근거 기반 개편"은 더 이상 반영되어 있지 않음.**

### Hero 섹션이 고정 헤더에 가려짐 (2026-09-09)
- **현상:** `Header`가 `fixed top-0`(높이 ~64px)인데 `Hero`는 `min-h-screen flex items-center`로 뷰포트 전체 기준 중앙 정렬만 함 → 좁은 뷰포트에서 상단 프로필 원(Dev)이 헤더 뒤로 잘려 보임.
- **해결:** `Hero` 섹션에 `pt-20`(80px) 추가해 헤더 높이보다 여유 있는 상단 여백 확보 (PR #10).
- **검증:** 브라우저 창을 1400x650, 1400x550으로 줄여 겹침 재현 조건에서 정상 동작 확인.

### 네비게이션 클릭 시 스크롤 이동 지점이 헤더에 바짝 붙음 (2026-09-09)
- **현상:** 각 섹션의 `section-padding`(py-16=64px)과 고정 헤더 높이(~64px)가 우연히 비슷해, 네비게이션 클릭 후 제목이 헤더 바로 아래 바짝 붙어 보임.
- **해결:** `about`/`skills`/`certifications`/`projects`/`contact` 5개 섹션에 `scroll-mt-24`(96px) 추가. `scroll-margin-top`은 `scrollIntoView()`에도 반영되어 `Header.tsx`의 JS는 수정 불필요 (PR #11).

### 다크모드 초기 진입 깜빡임 (FOUC)
- **현상:** 다크모드 적용 전 라이트 모드가 잠깐 보였다가 전환되는 깜빡임.
- **해결:** 초기 적용 방식 수정 (PR #3).

## 해결된 이슈 (계속)

### Footer 저작권 연도 하드코딩 (2026-09-09)
- **현상:** `© 2025 Portfolio`로 연도가 하드코딩되어 있었음.
- **해결:** `© 2026`으로 수정.

### Hero 소셜 아이콘 다크모드 미대응 (2026-09-09)
- **현상:** `Hero.tsx`의 Github/LinkedIn/Mail/Notion 아이콘이 `text-gray-600`만 있고 `dark:` 변형이 없어, 같은 역할의 `Contact.tsx` 소셜 아이콘과 다크모드 처리가 불일치.
- **해결:** `dark:text-gray-300` 추가.

### Footer 기술스택 목록과 실제 스킬 데이터 불일치 (2026-09-09)
- **현상:** `Footer.tsx`에 하드코딩된 목록(`Java/Spring Boot/Git·Slack/Docker·AWS`)이 `data/skills.ts`(단일 소스)와 어긋남 — `Slack`은 스킬 데이터에 아예 없고, Production 레벨인 GCP는 빠진 채 Project 레벨인 AWS만 언급됨.
- **해결:** 사용자 확인 후 `data/skills.ts` 상 Production 레벨 항목(Java, Spring Boot, Docker, GCP)으로 교체.
